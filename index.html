1. 적용 범위와 연락처

이 방침은 오프라인 퍼즐과 선택형 테마 구매를 제공하는 CraftFit Android 앱에 적용됩니다. 문의 및 개인정보 관련 요청은 materialstonegames@gmail.com으로 보내주세요. 같은 플레이 개선 기록 기능을 제공하는 웹 게임의 선택형 기록 처리에도 해당 절이 적용됩니다.

2. 앱이 기기에 저장하는 정보

앱은 퍼즐 진행, 완료 기록과 점수·시간, 발견·목격·제작 이력, 힌트 사용 이력, 접근성·소리 설정을 앱의 기기 내 저장소에 저장합니다. 이 정보는 이어하기와 게임 기능을 위해 기기에 저장됩니다. 전체 저장 데이터는 전송하지 않습니다. 아래 선택형 플레이 개선에 동의한 경우에만 정해진 플레이 이벤트를 별도로 전송합니다.

3. 수집·공유 및 권한

앱은 Google Play 테마 구매·복원 및 사용자가 동의한 플레이 개선 기록 전송에 인터넷 권한을 사용합니다. 구매 토큰·상품 식별자·앱 식별자를 Google과 개발자의 구매 검증 서버로 전송해 구매 상태와 환불·취소 여부를 확인합니다. 검증 서버는 구매 토큰을 요청 처리 중 메모리에서 사용하며 토큰 원문을 데이터베이스나 애플리케이션 로그에 영구 보관하지 않습니다. 호스팅 제공자는 보안과 서비스 운영을 위한 접속 정보를 처리할 수 있습니다. 게임 진행·힌트·발견 기록은 이 검증 요청에 포함하지 않습니다.

회원가입·광고 SDK·분석 SDK·원격 오류 수집은 제공하지 않습니다. 이름·전화번호·위치·연락처·사진을 요청하지 않으며 카메라·마이크 권한을 사용하지 않습니다. 카드 번호는 개발자가 수집하지 않습니다.

구매 검증 서버는 Google Cloud Run의 서울 리전(asia-northeast3)에서 운영합니다. 구매 검증 통신은 HTTPS로 암호화하며, 서버는 Google Play Developer API로 상태를 확인합니다. Google Cloud는 서비스 운영·보안을 위해 접속 IP 주소, 요청 시각·경로, 응답 상태 등의 요청 로그를 처리하며 현재 일반 요청 로그 보관 기간은 30일입니다. 위치를 추론하거나 광고·추적에 사용하지 않습니다. Google Cloud Pub/Sub는 구매 상태 알림을 전달하기 위해 구매 토큰이 포함된 미처리 알림을 최대 1일 보관하며, 처리 완료된 알림은 보관하도록 설정하지 않았습니다. Google의 서비스 처리에는 Google의 개인정보처리방침도 적용됩니다.

선택형 플레이 개선 기록

첫 게임 시작 전 별도 안내에서 동의한 경우에만 앱 실행·화면 이동, 스테이지 시작·완료·재시작, 튜토리얼 단계·건너뛰기, 제작 성공·잘못된 조합/배치, 힌트 사용, 플레이 시간과 발생 시각을 개발자의 분석 서버로 전송합니다. 앱이 생성한 임의 설치 구분값·실행 구분값, 앱 버전, Android/웹 구분과 개발자 테스트 여부를 포함합니다. 이름·입력 문장·광고 ID·하드웨어 식별자·기기 모델·구매 내역은 포함하지 않습니다. 임의 구분값은 개인의 신원으로 확인할 수 없으며 재설치·기기 변경 뒤 같은 사람인지 연결하지 않습니다.

목적은 첫 제작·완료율과 막히는 단계를 분석해 퍼즐을 개선하는 것입니다. 광고·판매·개인별 마케팅에 사용하지 않습니다. Google Cloud Run·Firestore의 서울 리전에서 처리하며 HTTPS로 전송합니다. 클라우드 제공자는 서버 운영에 필요한 IP·접속 시각 등의 요청 정보를 처리할 수 있습니다. 수집 동의는 선택이며 거절해도 게임과 구매 기능을 이용할 수 있습니다.

기기의 미전송 이벤트는 최대 240건·발생 후 30일 이내로 제한합니다. 서버 이벤트는 접수 후 30일이 지나면 통계에서 제외하고 자동 삭제를 요청하며 Firestore TTL 처리 지연으로 물리적 삭제가 보통 최대 24시간 늦어질 수 있습니다. 설정 → 플레이 개선 기록에서 자동 전송을 끄면 미전송 기록을 지우고 새 수집을 중지합니다. 내 관찰 기록 삭제를 누르면 전송을 중지하고 해당 설치의 서버 이벤트 삭제를 요청합니다. 인터넷이 없으면 삭제 요청 구분값만 기기에 보관해 연결 시 재시도합니다. 앱을 제거하거나 저장공간을 지우기 전에 서버 삭제 완료를 확인해 주세요. 제거 뒤에는 임의 구분값을 복원할 수 없어 같은 기록을 특정하기 어렵습니다.

삭제와 전송이 겹쳐 기록이 다시 저장되는 것을 막기 위해 서버는 삭제된 임의 구분값의 해시만 90일 보관한 뒤 자동 삭제합니다. 해당 해시에는 플레이 이벤트를 보관하지 않습니다. 게임 진행 초기화는 관찰 기록 삭제도 요청하며 구매 내역에는 영향을 주지 않습니다.

4. 보유와 삭제

검토용 코드를 발급받은 검토자는 설정의 검토용 접근 기능을 사용할 수 있습니다. 입력한 코드와 일회성 임의 확인값을 같은 서울 HTTPS 서버로 전송해 검토 권한을 확인합니다. 서버는 코드를 해시와 비교하며 코드 원문·확인값을 요청 처리 후 보관하지 않습니다. 발급된 검토 증명은 기기에 최대 24시간 저장하며 설정에서 즉시 종료할 수 있습니다. 일반 구매 내역에는 추가되지 않습니다.

게임 데이터는 앱을 사용하는 동안 기기에 남습니다. Android 설정에서 앱 저장공간의 데이터를 삭제하거나 앱을 제거하면 지워집니다. 되돌리기와 스테이지 재시작은 발견·힌트 이력을 삭제하지 않습니다. 앱의 Android 자동 백업은 비활성화되어 있으며 개발자는 이 데이터를 복구하거나 기기 간 동기화할 수 없습니다.

확인된 구매 증명과 복원에 사용하는 구매 토큰은 앱 전용 기기 저장소에 보관합니다. 게임 진행 초기화는 구매 내역을 삭제하지 않습니다. Google Play의 유효한 구매는 재설치·새 기기에서 같은 Google Play 계정으로 온라인 구매 복원을 할 수 있습니다. 클리어 기록의 복원은 구매 복원과 별개입니다.

서버가 보유하는 정보에 대한 열람·삭제 등의 요청은 위 이메일로 할 수 있습니다. 개별 요청을 식별할 수 있는 범위에서 처리하며, 보안·법적 의무로 보관해야 하는 정보가 있으면 해당 사유를 안내합니다. Google Play가 관리하는 주문·결제 내역의 처리 및 삭제는 Google의 정책과 절차를 따릅니다.

5. 사용자가 선택하는 공유와 문의

클리어 기록 공유를 누르면 스테이지 번호·점수·완성 시간이 Android 공유 화면으로 전달됩니다. 사용자가 공유 대상 앱을 직접 선택하며, 해당 앱의 처리에는 그 서비스의 방침이 적용됩니다. 문의 이메일을 보내면 이메일 주소와 사용자가 작성한 내용은 문의 응대에 사용됩니다. 문의 해결에 필요한 동안 보유하며 목적이 끝나면 삭제합니다. 해당 이메일의 삭제 요청도 위 연락처로 할 수 있습니다.

6. 스토어 구매와 웹페이지 방문

테마의 결제와 계정별 구매 내역은 Google Play가 처리하고 관리합니다. Google Play의 구매·계정 정보는 Google의 개인정보처리방침에 따릅니다. 이 방침을 GitHub Pages 등 외부 웹사이트에서 읽을 경우 호스팅 제공자는 자신의 방침에 따라 접속 정보를 처리할 수 있습니다. 이 페이지에는 별도 분석 도구, 광고 또는 추적 코드를 넣지 않습니다.

7. 변경 안내

데이터 처리 방식이 변경되면 앱과 공개 개인정보처리방침의 시행일 및 내용을 갱신합니다. 광고·계정·온라인 순위·인앱 구매 등을 추가할 때는 실제 기능과 데이터 처리에 맞춰 방침을 다시 작성합니다.
