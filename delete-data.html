CraftFit 데이터 삭제

앱 식별자: com.materialstone.craftfit
지원: materialstonegames@gmail.com

선택형 플레이 개선 기록을 지우려면

앱 설정 → 플레이 개선 기록 → 내 관찰 기록 삭제를 누르세요. 인터넷이 없으면 삭제 요청을 보관하고 연결 시 다시 시도합니다. 서버 삭제 완료를 확인한 뒤 앱을 제거하세요. 전송만 끄면 미전송 기록과 새 수집은 중지되며 기존 서버 기록은 보관 기간까지 남습니다. 이벤트는 접수 후 30일이 지나면 통계에서 제외하고 자동 삭제를 요청합니다. TTL 처리 지연으로 물리 삭제가 보통 24시간 늦어질 수 있습니다. 삭제와 전송 경합을 막는 임의 구분값의 해시는 이벤트 없이 90일 보관합니다.

기기의 퍼즐 진행을 지우려면

  1. Android 설정에서 앱 → CraftFit → 저장공간으로 이동하세요.
  2. 데이터 삭제를 선택하면 퍼즐 진행·완료 기록·발견·힌트·설정과 기기에 저장된 구매 증명이 삭제됩니다.

진행은 개발자 서버에 저장하지 않으며 삭제 후 개발자가 복구할 수 없습니다. Google Play의 유효한 구매 내역은 삭제되지 않습니다. 같은 Play 계정으로 온라인 구매 복원을 할 수 있습니다.

서버가 처리하는 정보의 삭제를 요청하려면

  1. 위 이메일로 제목을 ‘CraftFit 데이터 삭제 요청’으로 작성해 보내주세요.
  2. 삭제를 원하는 정보의 종류와 앱을 사용한 대략적인 날짜·시각을 알려주세요. 요청을 식별하기에 충분하지 않으면 확인에 필요한 최소 정보를 추가로 안내합니다.
  3. 식별할 수 있는 범위에서 요청을 처리하고, 삭제 또는 보관 사유와 기간을 답변합니다.

구매 검증 서버는 구매 토큰 원문을 데이터베이스에 저장하지 않습니다. 호스팅의 접속 IP·요청 시각·경로·응답 상태 로그는 30일, 구매 토큰이 포함된 미처리 구매 알림은 최대 1일 보관 후 자동 삭제됩니다. 클라우드 운영 로그의 개별 항목을 즉시 삭제하기 어려운 경우 보관 기간과 처리 가능 범위를 안내합니다. 법적 의무로 보관해야 하는 정보가 있으면 사유를 안내합니다.

삭제 요청 이메일은 요청 처리에 사용하며 목적이 끝나면 삭제합니다. Google Play가 관리하는 주문·결제 내역은 Google의 정책과 절차에 따릅니다. 데이터 삭제 요청은 구매 취소나 환불 요청과 별개입니다.

검토용 접근을 종료하려면

검토자는 앱 설정에서 ‘검토용 접근 종료’를 누를 수 있습니다. 검토 증명은 기기에 최대 24시간 저장됩니다. 검토 코드와 임의 확인값은 서버에서 요청을 처리한 뒤 보관하지 않습니다.
